    Lancer une actualisation
    {% set occupe = verrous or (progression and progression.en_cours) %}

    Une actualisation ciblée recalcule le dataset choisi puis tous ses descendants, dans l'ordre des dépendances. Un dataset dont un amont a échoué n'est jamais recalculé sur une entrée périmée : il reste marqué à recalculer. « Actualiser toute l'activité » interroge d'abord toutes les sources configurées (banque Qonto en lecture seule ; Hostaway extrait à l'instant par le pipeline GitHub — réservations, données financières, tâches de ménage — puis importé ; déclarations et factures de ménage), puis rejoue tous les calculs dans l'ordre des dépendances, et sauvegarde avant cela la base entière (restauration automatique si l'intégrité échoue après coup) ; « Simuler (dry-run) » calcule le même plan sans rien exécuter ni activer.
